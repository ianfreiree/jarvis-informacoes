# JARVIS — site informativo público

Este repositório é público e contém somente a apresentação do projeto, sua política de privacidade, seus termos de uso, os estilos dessas páginas e a comprovação pública de propriedade solicitada pelo Google.

## Privacidade obrigatória

- Nunca copie o aplicativo principal, seus bancos de dados, planilhas, mensagens, agenda, memórias, arquivos de configuração pessoal, músicas ou backups para este repositório.
- Nunca publique senhas, tokens, credenciais OAuth, chaves de API, arquivos `.env`, `.dpapi`, capturas de tela do usuário, e-mails pessoais, telefones, endereços ou identificadores privados.
- Não use dados reais do usuário em exemplos ou imagens.
- Inclua apenas arquivos explicitamente revisados. Nunca envie uma pasta inteira ou use inclusão indiscriminada de arquivos.
- O `.gitignore` usa uma lista de arquivos permitidos. Não amplie essa lista sem revisar o conteúdo e a necessidade da alteração. Arquivos ignorados ainda podem ser enviados por outros mecanismos; confira sempre a lista final.
- Use o endereço de privacidade do GitHub que termina em `@users.noreply.github.com` na autoria e no registro de commits. Não use e-mail pessoal.
- O repositório do aplicativo principal e seus backups são separados e privados. Não altere sua visibilidade nem os transfira para este destino.
- O arquivo de verificação do Google é público por finalidade e deve permanecer acessível enquanto for utilizado para comprovar a propriedade do site.
